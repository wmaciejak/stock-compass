# Stock Compass design

The user's supplied brief is the product contract. This is an architectural project in an empty workspace. User expressly authorized continuous implementation and reversible technology decisions, overriding intermediate skill approval gates.

React/TypeScript/Vite render a calm cream-and-green research workspace. FastAPI serves the built frontend on a single loopback port. Separate Python modules own provider interfaces, session normalization, TA-Lib indicators, causal setup rules, Backtesting.py simulation, educational text, SQLite and API routes. No financial calculations live in React. The active engine is TA-Lib, with no silent fallback.

Daily OHLC are consistently split/dividend adjusted for research and synthetic execution; volume remains provider-native. Raw downloads are retained in SQLite. All recommendations use completed exchange sessions, with a two-hour publication allowance. Corruption, interior missing sessions, stale prices and unknown adjustment conventions suppress actionable labels. Completed weekly context excludes unfinished weeks. Synthetic fixtures only use DEMO_ symbols.

Canonical versioned strategy functions drive both evaluator and simulations. Signals form at close and execute next open. Backtests compare identical dates, costs and sizing with buy-and-hold; recent 20% is a frozen-rule holdout. Long scenarios require defensible resistance above entry and stop below entry; no level means no scenario. Earnings unknown is a risk limitation.

Watchlist, settings, journal, snapshots and backtest configuration persist locally. CSV preview precedes import. Markdown and CSV exports include provenance. Demo works entirely offline. Startup uses a Python supervisor; port conflicts are checked before launching. Browser tests use fixed fixtures, separately from live integration smoke tests.
